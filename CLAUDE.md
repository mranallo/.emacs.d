# Emacs Configuration Guide

## Scope

This repository is a personal Emacs 30 configuration. Preserve existing user
preferences unless a task explicitly changes them. Prefer documented Emacs 30
APIs and small, verifiable changes.

## Architecture

- `early-init.el` contains startup-only settings. Avoid risky optimizations
  that temporarily disable GC, file handlers, or redisplay.
- `init.el` owns package declarations and user behavior.
- `custom.el` is generated by Customize and loaded at the end of `init.el`.
- `site-lisp/utilities/utilities.el` contains personal commands.
- `site-lisp/themes/nordic-night-theme.el` is optional and is not the active
  theme by default.
- `omarchy.el` delegates to the package-managed Omarchy integration only when
  `/usr/share/omarchy-emacs/config/omarchy.el` is installed.
- `shell-bashrc` provides the shell-mode environment used by Omarchy.

## Package Policy

Use package.el as the sole package manager. Declare archive packages with
`use-package`; declare source-control packages with `use-package :vc`. Do not
reintroduce straight.el or install the same package through multiple systems.

Do not refresh archives, clone repositories, install fonts, or compile
Tree-sitter grammars during normal startup. Explicit maintenance commands are
preferable for those operations.

## Current Stack

- Completion: Vertico, Orderless, Marginalia, Consult, Corfu, Cape
- Projects and navigation: Project, Avy, Treemacs, Ace Window, Winum
- Development: Eglot, Flymake, Tree-sitter, Magit
- Terminals: VTerm and VTerm Toggle
- Notes: Org-roam
- AI: Claude Code IDE
- UI: Doom Themes, Doom Modeline, Solaire, Nerd Icons

Eglot owns diagnostics through Flymake. Do not enable global Flycheck alongside
it without an explicit integration strategy.

Tree-sitter mode remapping must remain conditional on `treesit-ready-p`.
Grammar sources use HTTPS and installation is performed by
`M-x mr/treesit-install-grammars`.

## Validation

After editing Lisp:

```sh
emacs --batch -Q -l compile-init.el
emacs --debug-init
```

Also run `check-parens` over changed Lisp files when syntax is in question.
Compilation must not refresh package archives or otherwise require network
access.

## Generated And Local State

Do not commit package directories, native-compilation output, cache files,
backups, auto-save files, bookmarks, history, TRAMP state, or credentials.
Future backup and auto-save files are stored outside this repository under the
XDG state directory.
